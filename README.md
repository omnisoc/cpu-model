<h1 align="center">cpu-modle</h1>
The cpu-model is the core component of the OmniSoC project. It is a CPU model framework based on a JIT architecture that implements dynamic translation of CPU instructions.

# Quick Start

```bash
./run.sh clean                  # clean build
./run.sh build                  # Build porj
./run.sh test                   # test case
```
